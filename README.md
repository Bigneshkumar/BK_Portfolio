# 💻 Bignesh Kumar — Portfolio

My personal portfolio website showcasing my projects, skills, achievements, and journey as an aspiring AI Engineer & Full-Stack Developer.

🌐 **Live:** [bignesh-kumar-portfolio.vercel.app](bigneshkumar-portfolio.vercel.app)

---

## ✨ Highlights

- 🎆 **Interactive 3D Particle System** — Neural-network style particles with depth, mouse interaction, and connecting lines
- 🌀 **Smooth Animations** — Page transitions, hover effects, and micro-animations throughout
- 🎨 **Custom Gradient Design** — Premium dark theme with glassmorphism and custom scrollbar
- 📱 **Fully Responsive** — Optimized for desktop, tablet, and mobile
- 📊 **Live Stats Counter** — Animated statistics on the home page
- 🔮 **Floating Skill Orbs** — Interactive 3D-like visualizations
- 📝 **Blog with Reactions** — Personal blog with agree/disagree voting
- 🏆 **Certificate Gallery** — Tabbed showcase with modal preview
- 📧 **Working Contact Form** — Sends messages to my email
- 🎭 **Achievement Cards** — Showcasing milestones and journey

---

## 🛠️ Setup

```bash
git clone https://github.com/Bigneshkumar/Portfolio.git
cd Portfolio
npm install
npm run dev
```
